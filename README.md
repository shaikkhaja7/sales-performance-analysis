# Sales Performance & Profitability Analysis

## 📌 Project Overview
This project analyzes sales performance data to identify key business insights such as trends over time,
top products, regional performance, and the impact of discounts on profitability.

## 🛠 Tools & Technologies
- SQL (querying, aggregations)
- PostgreSQL
- Tableau Public
- CSV data export

## 🧩 Business Questions
- How do sales trends change month to month?
- Which regions and products generate the most revenue?
- How does discounting affect profitability?
